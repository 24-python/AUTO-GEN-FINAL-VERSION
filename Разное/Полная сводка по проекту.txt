## 3. БАЗА ДАННЫХ

### Таблицы (SQLAlchemy)

| Таблица | Поля | Назначение |
|---------|------|------------|
| **categories** | id, name, sort_order | 15 категорий с порядком сортировки |
| **objects** | id, category_id, normalized_name, display_name, base_name, modifier, sort_priority, created_at, updated_at | Объекты обработки (~200 записей) |
| **instructions** | id, object_id, cleaning_method, instruction_number, product_name, cleaning_technique, concentration, temperature, exposure_time, inventory, frequency, executor, control_method | Инструкции (2+ на объект) |

### Категории (15 шт.)

| sort_order | name |
|------------|------|
| 1 | Поверхности |
| 2 | Сантехническое оборудование |
| 3 | Санитарный пост |
| 4 | Мебель |
| 5 | Офисная техника |
| 6 | Многоразовые резиновые СИЗ |
| 7 | Бытовая техника |
| 8 | Инвентарь, посуда и т.д. |
| 9 | Моечный, уборочный инвентарь и оборудование |
| 10 | Посудомоечное оборудование |
| 11 | Холодильное оборудование |
| 12 | Дозирующее оборудование |
| 13 | Тепловое оборудование |
| 14 | Технологическое оборудование |
| 15 | Упаковочное оборудование |

### Ключевые поля

| Поле | Описание |
|------|----------|
| `normalized_name` | Для поиска (без знаков препинания, нижний регистр, с пробелами) |
| `display_name` | Красивое имя для вывода в техкарту |
| `sort_priority` | Приоритет сортировки (10-200, по зонам) |

### Приоритеты sort_priority

| Зона | Диапазон | Примеры |
|------|----------|---------|
| Потолок и всё на нём | 10-50 | потолок, светильники, вентиляция, вытяжные зонты |
| Стены и всё на них | 55-90 | стены, окна, двери, выключатели, завесы |
| Сантехника и санпост | 100-130 | раковины, унитазы, душевые, дозаторы |
| Мебель | 130-150 | столы, стулья, полки, стеллажи |
| Оборудование и инвентарь | 150-170 | тепловое, холодильное, технологическое |
| Моечный инвентарь | 170 | мопы, ветошь, щётки, вёдра, АВД |
| Пол и всё на нём | 175-200 | пол, трапы, стоки, коврики, паллеты |

## 4. ПАРСЕР (`parser/xml_parser.py`)

### Возможности

| Функция | Описание |
|---------|----------|
| **Два типа чек-боксов** | SDT (Structured Document Tags) + Unicode (☒/☐) |
| **Модификаторы** | Любое количество (☒ потолок ☒ П ☒ ОК) |
| **Нормализация** | `normalize_name()`, `normalize_potolok_name()`, `smart_normalize()` |
| **Кэширование** | Поиск в БД с кэшем категорий |

### Логика обработки

| Ситуация | Результат |
|----------|-----------|
| 1 чек-бокс в ячейке | Одиночный объект → в свою категорию |
| 2+ чек-боксов | Объект с модификаторами |
| Базовый ✅ + модификаторы ✅ | Каждый модификатор в свою категорию |
| Базовый ✅ + модификаторы ⬜ | Базовый в «Прочее» |
| Базовый ⬜ | Не добавляется |

## 5. ГЕНЕРАТОР (`generator/docx_generator.py`)

### Режимы генерации

| Режим | Описание | Флаг |
|-------|----------|------|
| **1** | По категориям (с заголовками, по алфавиту) | `mode=1` (по умолчанию) |
| **2** | По приоритету (единый список, сверху вниз) | `mode=2` |

### Возможности

| Функция | Описание |
|---------|----------|
| **Цветовое кодирование** | 4-я колонка окрашивается по словарю `PRODUCT_COLORS` |
| **Группировка объектов** | По полному совпадению ВСЕХ инструкций одновременно |
| **Вертикальное объединение** | Колонка 1 (всегда), колонки 9-12 (при одинаковых значениях) |
| **Оптимизация БД** | 3 запроса на всю техкарту |

### Цвета средств

|----------|------------|
| ХИМИТЕК ПОЛИДЕЗ®-СУПЕР | FFFFCC |
| ХИМИТЕК УНИВЕРСАЛ-ПД-Н | 99FF99 |
| ХИМИТЕК ЧУДОДЕЙ®-КОМБИ-ПЕНАКТИВ | 99CCFF |
| ХИМИТЕК ЧУДОДЕЙ®-CIP | 99CCFF |
| ХИМИТЕК ПОЛИКОР® | FFCCCC |
| ХИМИТЕК ЧАРОЙТ®-СПРЕЙ | 99FF99 |
| ХИМИТЕК СВЕЖЕСТЬ-АНТИСЕПТИК | FFFFCC |
