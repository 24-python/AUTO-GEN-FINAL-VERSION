## 🚀 ВОЗМОЖНОСТИ

- ✅ **Автоматический парсинг** чек-листов `.docx`
- ✅ **Поддержка двух типов чек-боксов**: SDT (Structured Document Tags) и Unicode-символы (☒/☐)
- ✅ **Обработка объектов с модификаторами** (любое количество)
- ✅ **Автоматическое определение категорий** из базы данных
- ✅ **Цветовое кодирование** моющих средств в техкарте

- ✅ **Вертикальное объединение ячеек** (колонки 1, 9-12)
- ✅ **Пакетная обработка** нескольких чек-листов (включая `.zip` архивы)
- ✅ **Веб-интерфейс** для загрузки и обработки файлов
- ✅ **Оптимизированные запросы** к БД (3 запроса на всю техкарту)
- ✅ **Экспорт/импорт CSV** для редактирования данных

## 📄 ФОРМАТ ЧЕК-ЛИСТА

### Требования

- Формат `.docx`
- Чек-боксы могут быть:
  - **SDT** (Structured Document Tags) — элементы управления содержимым Word
  - **Unicode-символы** — `☒` (отмечен) и `☐` (не отмечен)

### Структура ячейки

| Тип | Пример |
|-----|--------|
| **Одиночный объект** | `☒ светильники` |
| **Объект с модификаторами** | `☒ потолок ☒ П ☒ ОК` |

### Логика обработки

| Ситуация | Результат |
|----------|-----------|
| 1 чек-бокс в ячейке | Одиночный объект → в свою категорию |
| 2+ чек-боксов | Объект с модификаторами |
| Базовый ✅ + модификаторы ✅ | Каждый модификатор в свою категорию |
| Базовый ✅ + модификаторы ⬜ | Базовый в категорию «Прочее» |
| Базовый ⬜ | Не добавляется |

## 📋 ГРУППИРОВКА И ОБЪЕДИНЕНИЕ ЯЧЕЕК

### Группировка объектов

Объекты объединяются в одной ячейке через запятую **только при полном совпадении всех инструкций одновременно** (мойка + дезинфекция).

### Вертикальное объединение

| Колонка | Индекс | Условие объединения |
|---------|--------|---------------------|
| Объект обработки | 0 | Всегда (для сгруппированных объектов) |
| Инвентарь | 8 | При одинаковых значениях |
| Периодичность | 9 | При одинаковых значениях |
| Исполнитель | 10 | При одинаковых значениях |
| Метод контроля | 11 | При одинаковых значениях |

## ⚙️ НАСТРОЙКА

### Настройка шаблона (шрифт)

Для корректной генерации технологических карт **необходимо один раз настроить шаблон**:

1. Открыть файл `tech_card_templates/шаблон.docx` в Microsoft Word
2. Нажать `Ctrl + A` (выделить всё содержимое документа)
3. На вкладке **«Главная»** выбрать:
   - **Шрифт:** `Arial`
   - **Размер:** `9`
4. Нажать правой кнопкой мыши на стиле **«Основной текст»** → **«Обновить в соответствии с выделенным фрагментом»**
5. Сохранить и закрыть документ

| Действие | Результат |
|----------|-----------|
| Шаблон настроен правильно | Шрифт Arial применяется автоматически |
| Шаблон не настроен | Новые строки могут отображаться шрифтом Cambria |

### Добавление нового цвета для средства

В `generator/docx_generator.py` в словаре `PRODUCT_COLORS`:

```python
PRODUCT_COLORS = {
    "НОВОЕ СРЕДСТВО": "FFAA00",  # HEX-код цвета
    # ...
}
```

## 🔧 УСТРАНЕНИЕ НЕПОЛАДОК

### Объекты попадают в «Прочее»

**Причина:** `normalized_name` в БД не совпадает с тем, что ищет парсер.

**Решение:**
```bash
python -c "from db.database import SessionLocal; from db.models import Object; s=SessionLocal(); print([o.normalized_name for o in s.query(Object).filter(Object.display_name.like('%проблемный%')).all()])"
```

### Медленная генерация

**Причина:** Много запросов к БД.

**Решение:** Убедитесь, что используется последняя версия `docx_generator.py` (3 запроса на техкарту).

### Не все модификаторы находятся

**Причина:** Старая версия парсера.

**Решение:** Убедитесь, что используется `xml_parser.py` с поддержкой SDT и Unicode.

### Не отображается дезинфекция

**Причина:** Неправильная группировка инструкций.

**Решение:** Убедитесь, что используется последняя версия `docx_generator.py` с `_group_by_full_instructions()`.
